Install

curl -LsSf https://astral.sh/uv/install.sh | sh
uv tool install --python 3.12 "chronicle-context[graph]"
chronicle serve
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
uv tool install --python 3.12 "chronicle-context[graph]"
chronicle serve

Open http://127.0.0.1:3030. Chronicle needs Python 3.10 or newer.

Before you record

Give whatever runs Chronicle (your terminal, for example) Screen Recording and Accessibility under System Settings › Privacy & Security.

Capture needs X11 and is best effort. Install what you want recorded: sudo apt install xdotool x11-utils scrot xclip xprintidle tesseract-ocr.

Capture is best effort and needs no setup. For screen text, install Tesseract and put it on your PATH.

Then run chronicle doctor to see what this machine can capture.

Update or remove

uv tool upgrade chronicle-context
uv tool uninstall chronicle-context

Uninstalling keeps your data in ~/.chronicle. Delete that folder to remove it.
