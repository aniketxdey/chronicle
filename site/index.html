Harnesses for every AI, built from how you work

Models have gotten exponentially better in the last few years, but they still come plain out-of-the-box. In other words, models are great, but they don't know you.

We personally got tired of explaining our life stories in every prompt, so we built Chronicle: a desktop companion that watches how you actually work and turns what it learns into custom harnesses for any task, with integrations into every LLM provider.

As personal agents become more commercialized every day, we wanted to build something that bridges the gap between their, simply put, dumb pretrained corpuses and the ontology of how you work. The philosophy behind Chronicle is thus simple: an on-device context engineer for every AI you interact with. Record a session, get context files and workflows written from it, and combine them into a constantly evolving knowledge base that supports your own.

Chronicle's Ontology

Most harnesses are built for agents to know systems, not you. Chronicle instead builds harnesses directly on distinct artifacts it generates from its private, on-device sessions.

contexts/

Guidance for one kind of session, like an agent file. Researching job companies. You can also use one alone for a small session.

workflows/

Short procedures for one specific job, like a skill. Customizing resume bullets to keep their formatting and length.

graph/

Merged from the recordings you choose, down to the system events, so agents can look up what actually happened.

How it Works

1. Record a session

Pick a duration, or stop when you're done. Keystrokes are never recorded, and password managers are skipped.

2. Generate contexts and workflows

A model reads everything recorded and names the kinds of session it shows. You can use OpenAI, Anthropic, Gemini, OpenRouter, or a local model.

3. Ask your knowledge graph

Knowledge opens on a 3D graph of all your history with a chat beside it. Answers cite the frames they came from, and the chat can propose a harness to build.

4. Edit it like code

Harnesses open in an editor with your files on the left and a chat on the right. Ask for a change, review it, and undo it if it's wrong.

Everything shown is a synthetic sample workday, with no real screen data. Time spent waiting on the model is cut.

Try it in a minute

You need uv. The sample workday lets you explore everything before recording anything.

uv tool install --python 3.12 "chronicle-context[graph]"
chronicle demo
chronicle serve

Then open http://127.0.0.1:3030. The quickstart walks through the rest.

Your data stays yours

Everything lives in one local folder, with no account and no telemetry. Data leaves your machine only through tools you connect: an agent receives the tool results it asks for, and the model you choose receives window titles, URLs, and redacted screen text. A local model keeps all of that on your computer. The full policy is in PRIVACY.md.
